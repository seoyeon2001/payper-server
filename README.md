# 💳 payper-server

**내가 가진 카드로, 지금 내 주변 매장에서 받을 수 있는 혜택을 확인하는 앱 서비스 (Backend)**

---

## Getting Started

###  Requirements

| 항목         | 버전      |
|--------------|---------|
| Java         | 17      |
| Jakarta EE   | 8       |
| Spring       | 5.3     |
| Spring Security | 5.8     |
| MySQL        | 8       |
| Tomcat       | 11.0.9  |
| Build Tool   | Gradle  |
| ORM          | MyBatis |

---

###  Installation

```bash
$ git clone https://github.com/payper-devs/payper-server.git
$ cd payper-server
```
---

### Directory
```bash
src/
 ├─ main/
 │   ├─ java/          # Java 소스 코드
 │   ├─ resources/     # 설정 파일 (Spring, MyBatis 등)
 │   └─ webapp/        # JSP, static 리소스
 └─ test/
     └─ java/          # 테스트 코드
```
